# 자바스크립트의 변수와 스코프

자바스크립트에서 데이터를 저장하려면 변수를 사용한다. 선언 방식에 따라 스코프와 값 변경 가능 여부가 달라진다.

## 1. 변수 선언과 할당

변수는 데이터를 저장하는 이름이 붙은 공간이다. `let`또는`const` 으로 변수를 선언하고 `=`로 값을 할당

```js
let message;
message = 'Hello!';
```


## 2. 스코프(Scope)

스코프(Scope)는 변수에 접근할 수 있는 범위를 의미한다.  
함수나 블록 바깥에서 선언된 변수는 전역에서 접근할 수 있다.

```js
const name = '김사랑';

function sayHello() {
  console.log(name);
}

sayHello();
```

`name`은 함수 바깥에서 선언되었기 때문에 `sayHello()` 함수 내부에서도 접근할 수 있다.


## 3. var / let / const 비교

| 구분 | `var` | `let` | `const` |
| --- | --- | --- | --- |
| 재선언 | 가능 | 불가능 | 불가능 |
| 재할당 | 가능 | 가능 | 불가능 |
| 스코프 | 함수 스코프 | 블록 스코프 | 블록 스코프 |

- **`var`**: 재선언과 재할당이 가능하다. 함수 스코프를 사용하므로 현재는 잘 사용하지 않는다.
- **`let`**: 재할당이 필요한 변수에 사용한다.
- **`const`**: 재할당하지 않을 변수에 사용한다. 기본적으로 가장 많이 사용한다.

> **`const`를 기본으로 사용하고, 값이 바뀌어야 하면 `let`을 사용한다. `var`는 거의 사용하지 않는다.**

**var를 잘 사용하지 않는 이유**
- 함수 스코프라서 {} 밖에서도 접근될 수 있음
- 재선언 가능 → 실수로 같은 변수를 다시 선언할 수 있음
- 호이스팅 시 undefined → 선언 전에 접근해도 바로 에러가 안 나서 버그를 찾기 어려움

## 주의할 점

- `let`으로 같은 이름의 변수를 다시 선언하면 오류가 발생한다.
- 변수명은 숫자로 시작하거나 하이픈(`-`)을 사용할 수 없다. `let`, `class`, `return` 같은 예약어도 변수명으로 사용할 수 없다.
- 선언하지 않은 변수에 값을 할당하는 방식은 피한다. 엄격 모드에서는 오류가 발생한다.
- `const`로 선언한 변수에는 다른 값을 다시 할당할 수 없다.
