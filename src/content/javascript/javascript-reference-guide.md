# 자바스크립트 (JavaScript) 참고사이트


## 1. MDN JavaScript Reference

[MDN JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript)에서 자바스크립트의 기본 매뉴얼을 확인할 수 있다.

자바스크립트 문법이나 내장 객체, 메서드의 사용법을 찾아볼 때 참고한다.

## 2. Can I use

[Can I use](https://caniuse.com/)에서 사용하려는 기능을 브라우저가 지원하는지 확인할 수 있다.

특정 기능을 프로젝트에 적용하기 전에 브라우저별 지원 범위를 살펴볼 때 사용한다.

## 3. ECMAScript Compatibility Table

[ECMAScript Compatibility Table](https://compat-table.github.io/compat-table/es6/)에서 자바스크립트 기능 목록과 특정 엔진의 지원 여부를 확인할 수 있다.
